# 清叶 QINGYE · 自主建站测试项目

React 用户站、独立 React 管理站、Go API、PostgreSQL、Redis 与受控图片存储。当前测试版本为 `0.8.0-test.1`：用户站为 `20261111-home-background-r9`，管理站为 `20261111-hero-light-r8`，API为 `20261111-gallery-chat-r7`。

最新R9按用户反馈恢复本轮重构前的首页香槟光幕、细线流光和鼠标光晕，撤回R8网格、噪点及双光球；背景仅在首页挂载，保留双主题及详情、聊天等改动。用户确认聊天问题与Clash开启有关，本轮不改通信实现。见[R9记录](文档/业务验收与审查记录/HOME-R9--首页背景回退.md)。

本轮包括：管理工作台重构、WebTransport 商品咨询、在线／QQ 双咨询入口、二维码弹窗、昼夜双主题，以及首页、卡片、会员中心和大图集详情页的界面调整。保留热门推荐、轮播、用户发布与审核，未增加在线支付或订单结算。

详情页在页面内最多显示 12 张缩略图；完整原图通过全屏画廊继续浏览，不限制商品总图片数。数字统一使用本地托管的 JetBrains Mono。

HTTPS 页面已经部署，可信 IP 证书与自动续期已配置。WebTransport 公网 UDP 5179／5181 已连通；会员与管理员均通过可信HTTPS登录、Secure/HttpOnly Cookie、WebTransport连接和只读会话列表RPC实测。测试站不等于正式生产交付，8.140 生产站与 5178 历史原型保持原状。

源码位于 `代码/前端/用户端`、`代码/前端/管理端`、`代码/后端`。发布配置与证书续期脚本位于 `代码/部署/qingye-test`。服务器凭据、聊天记录、数据库备份和原图不进入 GitHub。
