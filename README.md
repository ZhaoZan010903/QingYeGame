API和管理端为`20261112-admin-products-r17`；用户端保留`20261112-storefront-backdrop-r16.2`，首页金线背景已复用至全部用户端页面。迁移0009前已备份，580条商品、48,337条图片关联及媒体摘要保留。固定表单、共享字典、会员草稿生命周期和手工轮播沿用[R16设计](文档/开发产出文档/FORMS-R16--固定表单字典与草稿生命周期设计.md)。当前版本以[发布记录](文档/计划/RELEASE--测试环境发布记录.md)和服务器回执为准。
