# 清叶 QINGYE · 自主建站测试项目

React 用户端、独立 React 管理端、Go API、PostgreSQL、Redis 与受控图片存储。项目正在替换 SaaS 建站能力，尚未切换正式生产站。

**当前工作状态（2026年11月12日）：R19图文聊天与头像已部署到152测试环境。** 用户端和管理端均支持图片配文字、纯图片消息、上传预览与重试、大图查看和本人头像设置，重新整理了会话列表、左右气泡与手机输入区。见[R19设计](文档/开发产出文档/CHAT-R19--图文聊天与头像设计.md)和[R19验收](文档/业务验收与审查记录/CHAT-R19--图文聊天与头像验收.md)。源码与文档随本提交同步GitHub。

保留R18查询优化：合并重复消息摘要查询、优化未读与商品统计、会话游标及消息历史分页。历史基线见[R18查询优化记录](文档/业务验收与审查记录/CHAT-QUERY-R18--聊天查询优化与规模验证.md)，包含图片与头像关联后的新测量见R19验收。

API、用户端和管理端统一为`20261112-chat-images-r19`。0011新增聊天附件关系及媒体用途、头像字段，已备份并核对8张业务表原有字段摘要不变；580条商品与48,337条图片关联保留。商品管理分页/回收站沿用[R17规则](文档/业务验收与审查记录/ADMIN-PRODUCTS-R17--商品分页与回收站.md)，固定表单与手工轮播沿用[R16设计](文档/开发产出文档/FORMS-R16--固定表单字典与草稿生命周期设计.md)。当前版本以[发布记录](文档/计划/RELEASE--测试环境发布记录.md)和服务器回执为准。

[数据库 E-R 图与核心字段](文档/开发产出文档/DATABASE-R17--数据库ER图与核心字段.md)：R17基础27张表，加上[R19附件与头像增量图](文档/开发产出文档/CHAT-R19--图文聊天与头像设计.md#3-数据库增量)，当前共28张持久表。

已实现商品浏览与筛选、完整图集、收藏、会员发布审核、运营配置和商品咨询。首页分开展示人工精选、热门、为你推荐与最新上架；热门按有效浏览、独立收藏与首次咨询人数加权，为你推荐采用 ItemCF 与属性匹配。聊天优先 WebTransport，兼容同源 WebSocket；详情页按需加载完整图集，不限制商品总图片数。

R19后端Linux全量247项、HTTP及聊天应用/领域包竞态169项通过，用户端126项、管理端68项、vet及三端构建通过；性能测试后再次执行3项附件权限集成测试。Chrome验证双向图文、持久化、大图、头像展示及深浅主题与手机布局；文件选择器的自动化操作仍受本机扩展权限限制，详细验证范围见[R19验收](文档/业务验收与审查记录/CHAT-R19--图文聊天与头像验收.md)。结果不代表生产容量或绝对无漏洞。

测试站已启用 IP HTTPS、Secure/HttpOnly Cookie；用户端和管理端分别构建、部署，API 仅监听服务器本机。`8.140.230.149` 生产站和 `5178` 历史原型保持原状。OSS/SeaweedFS 接入与图片迁移仍暂停；不新增支付、订单或真实短信能力，不向 GitHub 提交凭据、会员数据和原图。
