# QingYeGame -- 测试环境项目概述

清叶自主建站项目，采用 React 用户端、独立 React 管理端及 Go 后端，逐步替换现有 SaaS 的商品、会员、图片和运营配置能力。首期围绕展示、咨询和发布审核建设，尚未切换正式生产站。

**当前工作状态（2026年11月13日）：R20媒体改造已部署152测试环境，文档随本次提交更新。** 已实现1—99张本地队列排序后开始上传、持久分片会话、私有SeaweedFS/OSS适配、迁移/清理任务及上传停权。最新要求每张新商品图只持久保存一张安全重编码后的展示原图，不生成独立预览小图，保留浏览器blob预览。管理员新增可直接检查上架；页面内支持暂停重试，未完成File队列刷新或换浏览器后不自动恢复。见[R20架构](文档/开发产出文档/MEDIA-R20--媒体生命周期架构与故障一致性.md)、[实施与验收](文档/计划/MEDIA-R20--实施与验收清单.md)。

最终修复版已在152通过后端全量338项、race338项、针对性回归21项，均0失败/跳过；R20专项45项重复三轮，合计135通过。真实SeaweedFS/OSS的300张单original往返与清理用时42.04秒；限定卷实际回收122,880字节。源码/二进制govuln及vet/build通过，前端用户156/管理79项及构建通过。三端已部署152测试版20261113-media-r20，业务API5180/5182健康、0012及静态资源核验通过；最终API上两端7个浏览器核心流程及390×844视口复测通过，文档随本次提交更新，远端main与私有回执github_commit核对。小型合成图结果不代表真实大图或生产容量。 详情见[隔离验收记录](文档/业务验收与审查记录/MEDIA-R20-ACCEPTANCE--商品媒体隔离验收记录.md)。

当前测试站三端为 `20261113-media-r20`；0012及新存储配置经隔离验收后已启用，历史原图不纳管。发布前保留备份和旧资料摘要；产生R20对象后不能只回退R19二进制。最终版本见[发布记录](文档/计划/RELEASE--测试环境发布记录.md)与[AI交接说明](文档/计划/AI-HANDOFF--跨机器接手说明.md)。R16固定字典、人工轮播和R19图文聊天规则继续保留。

测试站已启用可信 IP HTTPS 和 Secure/HttpOnly Cookie，同端口 UDP 用于 WebTransport。浏览器通过各站同源代理访问 API；服务端校验会话身份范围、角色和 Origin，不能把同 IP 的不同端口当成 Cookie 域隔离。正式域名与管理网络策略仍待后续安排。

PostgreSQL 专用库、Redis 6381 和受控媒体目录位于 152 服务器。写入验收使用独立 `qingye_acceptance` 数据库、Redis 6382、媒体目录及 5184／5185 API，不向业务测试库灌入验收数据。测试用户端使用真实 API，失败不回退样例；管理端没有演示登录。短信供应商暂不接入，使用专用测试账户，未配置的短信能力明确返回不可用。

## 已实现的业务与边界

- 浏览、搜索与筛选 QQ 炫舞账号；首页分开展示人工精选、热门、为你推荐和最新上架。热门按有效浏览、独立会员收藏和首次咨询人数加权；为你推荐采用 ItemCF 商品协同过滤和属性匹配补齐，支持个人偏好开关与重置。
- 详情页内展示最多12张小尺寸图集预览，完整图集通过全屏画廊按需继续加载；R20新图预览使用同一展示原图，历史R19缩略图保持旧规则；商品图集不设固定总张数上限，上传与编辑分批处理。
- 会员收藏、浏览记录、自主发布与修改；固定表单的区服和性别必填，VIP等级和账号结构可选，出售与租赁共享字典。字典显示名称与存储编码分离，历史停用值可保留，新选值必须启用；自定义标签最多20个，每个5个Unicode字符，旧标签按兼容规则保留。
- R19及以前的会员草稿沿用已部署删除/72小时规则；R20仅为显式纳管新商品媒体实现5天暂存及下架OSS5天再ECS5天，不把历史创建时间当作新清理起点。文字保存与重复关联不无限延期，最终驳回/删除草稿按新状态清理；旧图、聊天、头像和其他有效引用受保护。新规则是否启用以部署回执为准。
- 管理端审核、上下架、图片排序、共享字典、交易分类、客服、内容与推荐规则可维护。首页轮播仅人工配置，数量上限1～30，独立文案和样式可预览，按钮固定“查看详情”，清空后不自动补商品。
- 在线与 QQ 双咨询入口、二维码弹窗；聊天优先 WebTransport，连接失败兼容同源 WebSocket。用户端与管理端分别登录，保留会话权限、消息去重和撤销规则。
- 电脑和移动端界面、昼夜双主题；首页背景与双下箭头沿用已确认的视觉要求。

用户已确认报价单位：账号出售为元，时日租号为元/日，周月租号为元/月。保留原始价格与分类，按确认分类映射业务报价，不换算租期、不覆盖人工报价。

旧站只读快照含576条公开商品；48,332张原图已复制到测试服务器，合计26.84 GB，历史SHA-256与图集核验见[发布记录](文档/计划/RELEASE--测试环境发布记录.md)。历史原图至OSS复制的最终完成状态另核对清单；旧 `oss_read` 预备仍关闭。R20存储接入只覆盖显式纳管新图，禁止顺带删除或重编码旧图。`8.140.230.149` 生产站只按授权读取资料，5178历史原型保留。

在线订单、支付、充值、积分、提现、结算和租期自动化不在当前范围。凭据、会员数据、聊天记录、生产导出、数据库备份及原图不提交 GitHub。测试结果以同版本证据为准，不作绝对无 BUG 或无漏洞的承诺。

## 源码与架构

当前源码沿用R14选型，使用 Go 1.27.4、Gin 1.12.0，后端构建、测试和扫描统一带 `-tags=nomsgpack`。Gin 负责路由与协议适配；领域和应用服务不依赖 Gin、HTTP 或数据库客户端。关键注释简洁说明权限、事务、并发与资源边界的原因。
