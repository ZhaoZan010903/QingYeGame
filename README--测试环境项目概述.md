# QingYeGame -- 测试环境项目概述

清叶自主建站项目，采用 React 用户端、独立 React 管理端及 Go 后端，逐步替换现有 SaaS 的商品、会员、图片和运营配置能力。首期围绕展示、咨询和发布审核建设，尚未切换正式生产站。

**当前状态（2026年11月11日）：R14 API 已部署至测试环境并通过健康检查。** API 发布目录为 `20261111-gin-r14`，两端前端仍为 R13（`20261111-review-r13`）；未修改部署配置或迁移业务库。最终后端全量及 Linux `-race` 均185项通过、0失败、0跳过；vet、源码与最终二进制 govuln 检查通过，隔离验收107／28／67项通过。浏览器最终两轮各9项检查通过，覆盖两端真实登录、WebTransport及WebSocket兼容，无页面异常或5xx；GitHub 随本提交交付，接手时用 `git rev-parse HEAD` 与服务器 `20261111-gin-r14-receipt.json` 的 `git_commit` 核对，详见 [R14 验收记录](文档/业务验收与审查记录/GIN-R14--Gin分层与安全性能验收.md)。

测试站已启用可信 IP HTTPS 和 Secure/HttpOnly Cookie，同端口 UDP 用于 WebTransport。浏览器通过各站同源代理访问 API；服务端校验会话身份范围、角色和 Origin，不能把同 IP 的不同端口当成 Cookie 域隔离。正式域名与管理网络策略仍待后续安排。

PostgreSQL 专用库、Redis 6381 和受控媒体目录位于 152 服务器。写入验收使用独立 `qingye_acceptance` 数据库、Redis 6382、媒体目录及 5184／5185 API，不向业务测试库灌入验收数据。测试用户端使用真实 API，失败不回退样例；管理端没有演示登录。短信供应商暂不接入，使用专用测试账户，未配置的短信能力明确返回不可用。

## 已实现的业务与边界

- 浏览、搜索与筛选 QQ 炫舞账号；首页分开展示人工精选、热门、为你推荐和最新上架。热门仅按浏览与收藏加权；为你推荐采用 ItemCF 商品协同过滤和属性匹配补齐，支持个人偏好开关与重置。
- 详情页内展示最多 12 张预览缩略图，完整原图通过全屏画廊按需继续加载；商品图集不设固定总张数上限，上传与编辑分批处理。
- 会员收藏、浏览记录、自主发布与修改；管理端审核、上下架、图片排序、分类筛选、客服、内容与推荐规则可维护。
- 在线与 QQ 双咨询入口、二维码弹窗；聊天优先 WebTransport，连接失败兼容同源 WebSocket。用户端与管理端分别登录，保留会话权限、消息去重和撤销规则。
- 电脑和移动端界面、昼夜双主题；首页背景与双下箭头沿用已确认的视觉要求。

用户已确认报价单位：账号出售为元，时日租号为元/日，周月租号为元/月。保留原始价格与分类，按确认分类映射业务报价，不换算租期、不覆盖人工报价。

旧站只读快照含 576 条公开商品；48,332 张原图已迁移，合计 26.84 GB，历史逐文件 SHA256 与有序图集核验记录见[发布记录](文档/计划/RELEASE--测试环境发布记录.md)。SeaweedFS 接入及后续图片迁移继续暂停，不删除或覆盖原图。`8.140.230.149` 生产站只按授权读取资料，不修改其网页、数据库、服务或配置；5178 历史原型继续保留。

在线订单、支付、充值、积分、提现、结算和租期自动化不在当前范围。凭据、会员数据、聊天记录、生产导出、数据库备份及原图不提交 GitHub。测试结果以同版本证据为准，不作绝对无 BUG 或无漏洞的承诺。

## 源码与架构

R14 当前源码使用 Go 1.27.4、Gin 1.12.0，后端构建、测试和扫描统一带 `-tags=nomsgpack`。Gin 负责路由与协议适配；领域和应用服务不依赖 Gin、HTTP 或数据库客户端。关键注释简洁说明权限、事务、并发与资源边界的原因。
