# 清叶独立管理前端

包名 `qingye-admin`，依赖与包版本以 `package.json` 为准。这是独立 React/Vite 项目，拥有独立依赖、登录页、路由、构建目录及部署入口。同源 `/api/v1` 只转发管理API，用户站不提供管理页面或管理接口代理。152测试站使用管理端5181及管理API5182；正式入口由独立部署配置决定，实际发布状态以发布回执为准。

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm dev
```

复制 `.env.example` 为 `.env.local`。`VITE_API_BASE_URL=/api/v1` 保持同源请求；`QINGYE_ADMIN_API_PROXY` 仅用于开发/预览代理。`VITE_PUBLIC_SITE_URL` 用于在新标签查看用户站及公开商品，并不共享登录状态。所有 `VITE_` 值会进入浏览器，禁止放入密码、数据库地址或供应商密钥。

正式构建设置以下公开配置后执行 `pnpm build`：

```dotenv
VITE_API_BASE_URL=/api/v1
VITE_ENVIRONMENT_LABEL=正式管理环境
# 替换为正式用户站完整HTTPS origin，包含实际独立端口，不带末尾路径
VITE_PUBLIC_SITE_URL=https://your-public-site.example
```

`VITE_PUBLIC_SITE_URL` 不可留空或沿用152测试地址，否则公开预览会打开错误站点。构建前核对 `.env.local`、`.env.production.local` 与进程环境变量；这些配置在构建时写入产物，改服务器环境文件后需要重新构建才能改变页面。短信能力由服务端决定，管理端不提供会员短信注册或构建短信开关。

管理后端只接受管理员账户，使用独立 `qingye_admin_session` Cookie 和管理会话 audience。前端还会检查明确的 `role=admin`，服务错误直接显示，不回退到演示数据。没有会员注册、收藏或会员投稿路由。管理图片使用 `/uploads` 与 `/admin/products/:id/images`，不调用会员图集接口。

## 管理端界面与看板口径

- 管理端使用 WattVision 深浅双主题。登录页和登录后顶部右侧共用太阳／月亮开关。首次打开默认深色，此后按当前浏览器保存的选择显示，同站标签页也会同步。浅色使用浅灰画布、白色卡片和深青色指标。基础颜色、字号和圆角在 `src/style.css` 中维护，KPI 使用本地 JetBrains Mono。
- 商品总数、公开可见数、会员总数和工作队列为本次查询时的快照。7 天／30 天仅切换趋势与商品互动排行。排行按去重商品浏览量排序，首页热门榜单另有自己的排序规则。
- 管理 API 的 `GET /admin/products?visibility=public` 与看板的「公开可见」共用用户站可见条件，包括商品有效、已上架、审核版本匹配和分类启用。管理商品响应的 `is_publicly_visible` 决定是否显示「公开页」。此功能需要配套版本的管理 API。
- 管理商品详情支持返回来源。看板入口保留统计期间、趋势指标，商品与审核列表保留分页筛选，接待台打开的商品保留咨询会话。直接打开详情时，返回入口为商品列表。

登录标识支持已开通的账号名或手机号；后端接口沿用字段名phone，不表示仅能使用手机号。登录表单不自行限制已有密码的最短长度，常规seed-user开户仍要求12—72字节。不得将本次用户指定的测试账号例外扩展为默认开户规则，凭据不写入源码。

pnpm-workspace.yaml锁定electron-to-chromium 1.5.478以满足本次依赖发布时间策略，并仅允许已审阅的esbuild 0.28.2安装脚本。升级这两项时重新审阅与测试，不关闭供应链策略。

管理功能包括商品审核、编辑、图集追加及排序、上下架、人工精选、会员查询和停用、客服与二维码、分类筛选、说明页面、首页和推荐配置。写入保留服务端版本冲突错误，未保存内容不会自动覆盖新版本。经营方已确认出售元、时日出租元/日、周月出租元/月，分别显示服务端account/day/month正式报价；原价和原分类保留。只有不能安全映射、仍为unknown的异常条目显示待核对说明。

`../共享` 提供两端共用的类型、展示和上传组件等基础模块，不共享应用入口或登录会话。管理项目不导入 `../用户端/src`；用户站不产出管理模块。管理端操作演示仅在当前页面运行，不提交业务数据，可作为正式管理台的使用帮助保留。

部署 `dist/` 到独立HTTPS站点的 `/`，所有页面路由回退至本项目 `index.html`，API错误不得回退到HTML。正式入口使用独立监听端口并保留服务器已有项目；`pnpm preview` 仅供本地构建检查，不作为长期服务。登录、Cookie、Origin、媒体、上传和审核必须通过实际管理入口验证，不能借用户站origin验证管理写入。站内媒体与上传继续由同源API授权；WebSocket、WebTransport与Turnstile配置需匹配新的正式入口。
