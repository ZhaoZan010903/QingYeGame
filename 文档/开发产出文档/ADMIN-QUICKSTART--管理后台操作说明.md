# 管理后台操作说明

更新：2026-11-11。此文对应本地重构版本，服务器仍为旧版。本次管理后台采用明亮工作台、固定菜单、清楚的操作名称；用户站的奢华展示风格不直接套用到后台。

## 常用工作

| 想完成的事 | 去哪里 | 怎么操作 |
| --- | --- | --- |
| 查看当天要处理的事 | 工作台 | 查看待审核、已上架、草稿，点击对应卡片进入列表 |
| 上架平台商品 | 商品管理 → 新增商品 | 填资料 → 整理图片 → 检查并上架；尚未完成时保存草稿 |
| 修改已有商品 | 商品管理 → 编辑 | 编辑资料后确认保存；修改公开内容时查看页面上的审核／上架提示 |
| 审核会员上传 | 待审核 | 核对资料和完整图片，通过或填写原因退回 |
| 修改首页某个区域 | 首页装修 | 在页面位置图中点选精选轮播、快捷入口、热门推荐、最新上架或发布邀请，再改右侧内容 |
| 调整推荐展示 | 首页装修 → 热门推荐 | 修改标题、说明和数量；排序规则到热门推荐页面处理 |
| 更新推荐榜单 | 热门推荐 | 查看当前规则与榜单，点击更新；技术权重收在高级区域 |
| 更换二维码 | 客服与二维码 | 选择客服、修改信息／上传二维码、选适用入口，再保存 |
| 修改分类筛选项 | 分类与筛选 | 勾选可用报价单位，编辑筛选分组和选项；保留已有选项标识 |
| 接待咨询 | 在线咨询 | 连接成功后点击开始接待，选中会话，查看商品卡片并回复 |
| 不确定如何操作 | 操作演示 | 打开对应演示，在示例内容上练习 |

## 首页装修的“位置图”

位置图明确说明修改内容出现在用户站哪里。修改标题、说明、数量时，预览同步变化；各模块可开关、调整顺序。快捷入口通过下拉选目标页面，不要求运营人员自己填写 URL。

预览用于确认布局位置，示例商品不代表真实榜单。保存后到用户站检查实际展示。

## 商品编辑的三个步骤

1. **商品资料**：选择分类、出售或租赁、报价单位，填写标题、属性及说明。
2. **商品图片**：上传、查看、排序和重试失败图片；第一张用作封面。没有固定总张数上限，仍受单文件大小和单批并发控制。
3. **检查并上架**：核对预览，再选择保存草稿、确认上架或提交审核。会员投稿与平台商品使用各自流程。

未保存的内容离开页面时会提醒。保存过程中限制重复操作；后台读取失败会显示重试，不显示成一个空白的新商品表单。

## 操作演示

已经提供“上架商品、修改首页、更换客服二维码、审核投稿、接待商品咨询”五类演示。演示中的修改和保存只作用于本地示例，不调用实际业务写接口。演示通过不代表真实商品已经验号，也不会自动发布商品。

## 聊天接待

每人默认同时接待 3 个咨询。系统只分配给在线、开启接待且仍有空位的管理员。暂停接待后仍可回复原有会话；完成后点结束咨询可释放位置。

连接中断时页面显示原因，草稿保留。不要连续改写同一条待确认消息后反复发送；先用原内容重试，可依靠重试标识避免重复。未读角标、站内提醒在两个端都有，桌面提醒需主动授权并保持页面打开。
