## 1 范围与数据边界

用户前端范围为首页、商品列表与详情、客服、登录注册与找回密码、收藏、发布与我的发布、个人资料及说明页。管理后台、Go 服务、短信发送、对象存储和数据库迁移不因页面完成而视为已经交付。

原 `文档/原型代码/HTML/` 保留为视觉参考。概念图片、样例商品、样例排序与浏览器本地演示资料必须明确标识；生产 API 失败时不得自动切回演示数据。不得将本地保存、样例登录或模拟审核显示为真实服务成功。

不增加订单、购物车、充值、积分支付、提现、结算、自动租期等入口。发布审核与账号资料核验分开；审核通过不等于验号通过或保障承诺。没有客服配置时显示缺失状态，不生成二维码或私人联系方式。

## 2 页面与交互检查

| 页面 | 检查内容 |
| --- | --- |
| 首页 | 全屏品牌开场使用无外框双下箭头；同一组标题随滚动缩小、上移并融入原首页，支持反向恢复及减少动态效果；热门推荐与最新上架分区同时展示，每区最多 6 条；精选、热门与最新三区互相去重；桌面三列两行，手机单列 |
| 轮播 | 前后、指示点、暂停、键盘与触屏可用；用户操作后停止自动播放；隐藏、离屏、弹层及减少动态效果时暂停；非当前项不可聚焦 |
| 搜索与列表 | 编号、标题、区服关键词；集市单一搜索框随滚动融入顶部导航，手机收起后可展开；排序显示“排序方式：当前选项”；下拉支持键盘及禁用原因；同组 OR、跨组 AND；URL 保存筛选与排序；返回后恢复浏览；空、加载、失败分别呈现 |
| 价格 | 卡片价格单位用明亮的独立标记显示；出售总价与小时、日、周、月价不混合筛选或排序；未选统一单位时要求先选择；客服报价显示明确文案 |
| 移动筛选 | 打开时复制当前条件；应用才生效；取消不改变结果；支持清空和逐项移除 |
| 商品详情 | 属性、价格单位、介绍、图集与客服商品编号完整；图片失败有回退；图集继续加载且无固定总量上限 |
| 登录与收藏 | 游客可浏览和咨询；收藏、发布要求登录；登录后返回原位置；会话失效反馈明确；注册确认协议，密码重置后重新登录 |
| 发布 | 草稿允许未填完整；提交检查必填、报价单位和有效图片；待上传、失败、处理中图片不能静默漏掉；失败保留表单 |
| 图集编辑 | 可连续追加、排序、移除和重试；单文件、每批和并发参数独立管理；不限制商品图片总数；显示已保存数量 |
| 我的发布 | 草稿、审核中、已展示、退回修改、已下架分开显示；审核原因可见；撤回、下架、编辑按当前服务端状态处理 |
| 个人中心 | 脱敏资料、昵称、收藏、发布与当前设备浏览历史；可清空历史；退出后清除当前登录状态 |
| 说明与客服 | 联系用途和商品编号可读；协议、隐私和保障文案由运营确认；无配置明确说明，不编造承诺 |

检查宽度覆盖 320、390、768、1440px。商品主列表依次为手机一列、平板两列、桌面三列。长标题、长编号、不同价格单位不能撑开页面。弹层支持 Esc、焦点约束与关闭后的焦点恢复；主要触控区域不小于44px。

## 3 对接约定

接口基准为 [接口清单](../前期设计文档/07-api-outline--接口清单.md)，前缀 `/api/v1`，JSON 成功体含 `data`，分页含 `next_cursor`，错误含 `code`、`message`、可选字段错误及 `request_id`。生产会话使用服务端 Cookie，前端请求携带凭据；不得用前端状态代替权限校验。

| 接口域 | 关键约束 |
| --- | --- |
| 公开商品 | 只返回当前版本可公开商品；404 统一不可见或不存在；410 只返回下架状态，不泄露原资料 |
| 分类筛选 | 使用后端配置的分组及选项编码；未知参数由服务端拒绝；不能把 V3 单选样例当作最终配置 |
| 首页推荐 | 前端保持服务端排序，真实排名不在浏览器重算；补位来源真实标识；详情成功后上报浏览，图片切换不重复上报 |
| 图片页 | `cursor`、`limit`、`expected_version`；409 时重新加载，不拼接两个版本；无固定总张数上限 |
| 发布写入 | 先建草稿，再分批关联媒体；报价为十进制字符串或 null；不提交 owner、审核状态、精选权重等受保护字段 |
| 图集变更 | 同一商品关联、排序、移除串行提交并使用最新版本；上传文件可受控并发；追加使用去重请求编号 |
| 上传 | 签名参数、实际上传、完成核验分开；进度来自真实请求；取消、失败重试保留其他文件；不把对象上传成功等同于审核可用 |
| 认证 | 短信成功响应后才启动倒计时；保存 challenge_id 与用途；429 尊重服务端频控；不得假报已发送 |
| 收藏 | 本人数据隔离；重复添加幂等；失效商品保留简要占位及取消收藏，不带出私有内容 |
| 错误 | 401 登录返回、409 版本冲突、410 下架、422 字段错误、429 限流、503 可重试；网络失败不清空表单 |

## 4 文档中的待定规则

- R02“公开商品编辑后立即停止展示并重新审核”仍待确认。接口清单中的对应行为是建议契约，不能因前端实现而认定经营规则已批准。上线前应按最终服务端规则统一。
- R01 报价口径、R03 热门权重、R05 联系方式、R08 认证配套和 R10 上传参数仍按 [待确认事项](../前期设计文档/09-review-items--需求确认与审阅记录.md)审阅。前端演示参数不修改该确认状态。
- 早期文档中的“仅需求稿、尚不开发”描述是历史阶段。当前已明确授权 React 用户前端开发，不能据此停止实现。
- V3 的核验、信誉、热度与概念图是样例。正式数据和法律文案需另行提供，不从样例推导业务承诺。

## 9 原型性能与可配置结构（0.6.0-prototype.1）

手机滚动动效采用缓存布局、合并帧更新和局部合成变换。首页过渡结束停止标题样式更新；集市单输入框保留草稿并缩入导航。其他页面按路由加载，演示样例与真实接口依赖分离。触屏保留整体画面，减少持续重绘特效。

首页 `presentation` 由 `lib/home-content.ts` 统一校验并提供默认值；API可返回分区文案、顺序、数量、快捷入口和轮播间隔，库存和排序继续使用服务端结果。当前未建设后台编辑界面，也未把原型中的经营建议转为正式规则。扩展点、配置示例和验收边界见[原型工程说明](15-prototype-architecture--原型工程说明.md)。
