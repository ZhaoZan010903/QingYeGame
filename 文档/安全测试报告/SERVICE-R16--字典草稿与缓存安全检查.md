# SERVICE-R16 -- 字典、草稿与缓存安全检查

本轮变更与结果汇总见[R16全栈验收](../业务验收与审查记录/SERVICE-R16--固定表单字典与安全清理验收.md)。以下记录安全边界，最终扫描和隔离安全断言计数以该报告为准。

| 边界 | 实现与验证 |
| --- | --- |
| 字典权限与并发 | 仅管理API可写；校验会话及来源，版本冲突返回409；已引用编码不能直接删除，停用不重写历史商品 |
| 固定表单 | 后端验证单值属性、启用字典、完整资料必填与20×5标签；旧自定义表单写接口返回410，不信任前端隐藏字段 |
| 草稿所有权 | 只有本人从未公开的非导入草稿可删除，版本检查防止误删新修改；软删除保留编号和幂等记录，重放不创建第二件商品 |
| 上传滥用 | 未公开上传字节与数量预留受事务控制；72小时过期回收配合2GiB、1000个待关联文件、20份未公开草稿额度，不限制已上架图集总张数 |
| 文件清理 | 标记为可管理的新文件才可回收；加锁后另一个SQL重新检查商品、客服、审核快照和共享路径引用；只允许已知生成路径，拒绝符号链接绕行，旧导入目录不删除 |
| 回收容错 | 文件删除失败记录重试，不回滚成可公开媒体；失败任务不能持续占满批次阻止其他文件清理 |
| 首页缓存 | Redis仅缓存展示配置，不缓存私密资料或权限；随机数据库版本隔离旧请求，短超时与合并回源避免缓存异常长时间阻塞；错误结果不当作空成功值缓存 |
| 可视化样式 | 字体白名单、数值范围与十六进制颜色校验，不允许任意CSS、脚本或外部字体地址 |
| 私密资料 | 延续AES-GCM与隔离授权读取；公开商品、聊天快照、发布预览和首页缓存不包含QQ密码 |

扫描不替代访问控制和并发测试。扫描依据当时漏洞数据库，不能承诺未来无新增漏洞。未执行破坏性生产攻击、外部第三方渗透或长时间资源耗尽测试。
