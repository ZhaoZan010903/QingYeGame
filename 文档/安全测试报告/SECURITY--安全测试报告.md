# 安全测试报告

更新：2026年11月11日。对象：`0.7.0-test.1`隔离验收版本及对应依赖。已完成本轮有限范围的动态检查、依赖扫描和三轮代码/业务复核；**不代表零BUG、零风险或专业渗透认证**。目录迁移后的测试与构建已复核，R4已部署并通过18项外网浏览器检查；R5定点补发的迁移与复验由发布记录补充。

## 环境、顺序与结果

动态写测试只在152服务器的`qingye_acceptance`环境执行：public/admin API分别为本机5184/5185，独立数据库角色、Redis6382、系统用户及媒体目录。未对8.140生产站或5179业务测试库执行攻击性写测试。请求为服务器本机HTTP，没有TLS和互联网链路，不代表对外端口、证书或全部Nginx行为的动态认证。

R3按功能→并发→安全执行。报告显示功能107项、并发28项、安全67项断言均通过；安全阶段时间为北京时间2026年11月11日02:14:49—02:14:53。67项包含健康与身份准备断言，不能称为67种漏洞攻击。独立管理浏览器另外完成17步真实API验证，包括双会话、上传、发布、下架与退出；该浏览器环境为本地隔离代理，并非最终外网部署。

最终R4精确依赖修复后再次按同一顺序执行，功能107、并发28、安全67项均通过，使用新的独立state文件。最终部署后确认5179/5181正常响应，CSP、nosniff及页面no-store生效，API5180/5182与数据库、两个Redis实例均仅监听本机。完整浏览器结果及产物校验见[发布记录](../计划/RELEASE--测试环境发布记录.md)。

## 动态覆盖范围

| 类别 | 实际检查 |
| --- | --- |
| 双入口身份 | 管理员不能在public登录，会员不能在admin登录；修改Cookie名称仍不能跨audience使用；同主机同时带两种Cookie不能交换身份；跨端退出不能注销另一端会话 |
| 管理路由 | public无管理业务接口，admin无会员投稿写入口；管理预览与媒体要求管理员身份 |
| 来源与字段 | 错误、空和`null`写Origin被拒；会员不能指定owner/source/status；设置白名单拒绝修改session_secret；管理员不能停用自己 |
| 输入与路径 | SQL元字符仅作为搜索值；检查若干编码路径穿越样例；拒绝不合法上传文件名、SVG、超字节限制、非图片字节、MIME伪装和超大像素 |
| 媒体权限 | 其他会员和匿名用户不能读取私有图片；管理上传票据不能在public使用；下架后原图与已有缩略图均拒绝公开读取 |
| 下架数据 | 详情返回410；当前下架收藏只返回占位，不含私有介绍、图片和图片数量 |
| 频控 | 有界密码失败请求达到Redis限流并返回429；没有为测试关闭限流 |
| 并发权限一致性 | 前一阶段已验证同版本只允许一次编辑/审核，以及新建和追加图片幂等，见[性能与并发报告](../性能测试报告/PERFORMANCE--性能测试报告.md) |

这些检查是确定的有限用例，不覆盖所有编码组合、授权状态、未知攻击或资源耗尽方式。

## 依赖扫描与修复

原始Go扫描报告6个可达公告，已升级`pgx/v5`至5.9.2、`x/image`至0.45.0、`x/text`至0.41.0，并同步解析`x/sync`至0.22.0。修复依据与各公告的实际适用条件见[后端第三轮安全记录](backend-security-round-3--后端第三轮安全检查.md)。

R3源码和未精简构建复扫为0可达、0导入包，但保留19项模块公告；精简二进制扫描信息不足时呈现不同结果。发布前R4进一步精确锁定官方x/crypto修复提交 `v0.58.1-0.20261009181718-2f1f834330b2`，关联x/text0.43、x/sync0.24，最低Go1.26。**最终源码、实际精简Linux产物和模块级扫描均无已知漏洞告警**。修复提交不是稳定tag，选择依据与此前扫描差异完整保留在后端安全记录；新增导入、功能或工具链变化后仍需重扫。

用户端和管理端的`pnpm audit --json`修复报告中，info、low、moderate、high、critical均为0。该结论对应当次依赖锁和漏洞库时点，历史原型不属于当前部署依赖，也不代替后端或运行环境检查。

后端依赖修复后，完整真实PostgreSQL/Redis测试、vet、本机构建及Linux构建通过，具体命令和产物散列见后端第三轮记录。目录重排后，两个前端依赖链接已重建，用户46项、管理11项测试及各自构建再次通过；Go构建和19项工具回归也通过。最终发布产物和外网切换仍需独立记录。

## 测试误报及审计保留

此前安全测试在“下架收藏隐藏私有介绍”处误报：旧断言扫描整个收藏响应中的通用介绍文字，同库先前仍公开商品的合法内容也会匹配。现已按本轮商品ID定位唯一条目，再检查offline状态、空图片、零图片总数与无介绍；没有放宽服务端权限。

新增回归覆盖合法公开收藏共存，以及当前条目缺失、重复、状态错误、私密介绍或图片泄漏等失败情形。修正后重新执行完整R3安全阶段，67项通过。原始失败报告仍保留在私有审计目录，不删除失败历史，也不把这次误报描述为修复了不存在的产品越权漏洞。

## 静态审阅与运行边界

三轮发现与修复见[三轮汇总](../业务验收与审查记录/18-review-and-test-record--三轮审查与验收记录.md)。其中包括初始化误绑定外网、迁移跳转白名单、图库关联漏核验、图集版本混用、后台配置校验以及密码比较成本一致性。公开商品使用明确字段投影，不公开所有者、原始导入载荷、审核备注或旧图片来源；审核快照仍在管理权限内。

Nginx的CSP、gzip、缓存、访问日志及systemd最小写路径已经静态检查。访问日志不记录query，但错误日志不保证采用相同脱敏格式，仍应私有保管。原图、凭据、Cookie、真实会员数据、数据库dump与原始日志不提交Git。

**同一IP不同端口不是Cookie域隔离。** 当前服务依靠独立Cookie名、数据库audience、角色、账户状态和精确Origin联合控制；用户确认先IP/HTTP测试，`Secure Cookie`随HTTPS后续启用。当前没有对网络窃听、跨地域攻击、全部TLS策略、第三方短信、专业模糊测试或长期拒绝服务攻击作出通过结论。
