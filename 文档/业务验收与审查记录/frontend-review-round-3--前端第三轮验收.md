- 这是测试工具等开发依赖的修复，不将原告警描述为线上业务运行时漏洞。审计0表示检查时公告数据库没有报告依赖问题，不代表不存在未知漏洞。

私有审计证据为 `deploy-private/qa/web-audit-r3-fixed.json` 和 `admin-audit-r3-fixed.json`，不提交凭据或私有运行日志。

## 中文目录迁移与外网复验

目录整理至`代码/前端/{用户端,管理端,共享}`后，Windows原node_modules中的绝对junction失效。两个业务项目分别按原锁文件执行`pnpm install --frozen-lockfile --force`重建链接，没有修改依赖版本；再次通过46项用户测试、11项管理测试和两个生产构建。

2026年11月11日，对152测试站实际用户入口5179、独立管理入口5181完成18项外网浏览器检查：匿名和会员不能进入管理接口；管理7页真实读取；会员与管理员身份及退出互不串用；完整列表576项，在该次检查时经营方尚未确认单位，旧价保持unknown/null；桌面和手机集市搜索、滚动收起及展开后保留输入；CSP及nosniff响应头存在。该报价状态是当时的历史结果，随后确认及迁移规则见下节。全程没有新增业务商品或修改运营配置，浏览器pageerror为0。手机输入聚焦时保持展开是预期行为，脚本按真实焦点状态处理收起操作。

轮播使用267字真实原标题及原站拼图，在1440、1280、390宽度检查：标题不超过3行，桌面图文独立两列、手机图上文下，均无交叠或横溢。私有证据为`round4-remote-visual-report.json`及对应carousel截图。

真实商品`b4c75131-3c1a-51a1-a7a4-e0baa14f9242`的200张图片自动顺序加载到末张，分页最大并发1，本次外网滚动测量约35秒，包含真实网络和媒体加载，不作为所有设备的耗时承诺。单独检查首屏时仅请求1张原图和20张缩略图，没有一次下载200张原图。原始数据实际最大200张；超过200的无上限行为由前两轮202/567/1001张回归验证，不虚称旧站存在更多张数的商品。

截图验证补充等待`img.complete`与`decode()`，因为naturalWidth可能在传输未完成时已有值。真实首图1024×768和末图451×292均完整解码，媒体HTTP错误为0。人工查图进一步发现详情及放大窗继承封面cover导致原图边缘裁切，已将这两处原图改为contain；放大窗使用商品编号和计数，完整标题继续保留于详情，避免长旧标题占满手机窗口。放大区依据视口高度显示。新用户站构建通过，本地新构建连接真实原图的1440/390截图已验证无裁切、无横溢；最终远程补发及复核见发布记录。

私有证据：`round4-remote-browser-report.json`、`round4-remote-gallery-decoded.json`、`round4-gallery-contain-report.json`及配套截图。脚本中期的定位等待失败保留于私有历史，最终结果以完整报告为准；初次传输未结束的占位截图不作为原图可见证据。
