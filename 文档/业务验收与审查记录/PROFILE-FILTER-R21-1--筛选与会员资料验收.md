# R21-1：筛选与会员资料验收

2026年11月13日。范围与规则见[实施计划](../计划/PROFILE-FILTER-R21-1--筛选与会员资料调整.md)及[接口与数据设计](../开发产出文档/PROFILE-FILTER-R21-1--筛选与会员资料设计.md)。本轮用户明确授权测试通过后提交私有 GitHub 并部署 152 测试站。

## 实际变更

- 区服筛选按“一舞时光、拾忆光阴、十年之约、其他”，VIP 按“星钻、银钻、金钻、彩钻、王钻”展示。保留字典原编码，“其他大区”只调整展示名称。
- 删除账号结构筛选及旧链接残留条件，不删除商品结构字段。热门关键词按用户截图初始化 23 项，管理端共享字典支持增删、改名、启停、排序与版本检查。
- 昵称经管理员审核才变更，30 天间隔从通过时起算。待审期间不改旧昵称；拒绝可重新申请；手机新注册默认“清叶会员＋后四位”。
- 会员仅能选择启用头像库项；服务端封闭会员自传头像及旧关联接口绕过。管理员维护名称、排序与启停，停用不破坏当前使用者或清理库引用。
- 首批十张卡通漫画头像，包括日漫、仙侠、线绘三类；[素材来源与生成提示词](../../代码/素材/头像库/README--首批头像来源.md)随代码保存。生成资产已压缩至头像上传额度内，运行时不访问第三方头像服务。
- 登录页移除左侧人物图并重排文案；首页和账号集市手机端两列，桌面端三列。

## 三轮审查

1. 实现自审：昵称事务锁顺序与单待审约束、头像库选取/停用竞态、旧接口绕过、上传取消与 GC 引用保护。
2. 交叉审查：两位实现代理独立检查对方后端；补充关键词非法 UTF-8 和控制字符拒绝、头像维护操作者锁、审核列表先分页后关联。
3. 集成审查：主代理核对前后端契约、历史编码、源文件与测试产物一致性，统一昵称前端与后端 30 个 Unicode 字符上限；结合真实浏览器与部署后检查复核。

本地Vite经SSH代理的初轮记录出现4次`socket hang up`代理500，服务器API健康。保留原始失败报告，业务写入已成功的流程不重复提交；之后分离匿名布局、登录资料只读复核。最后主代理独立检查320集市，分类/商品均200、9张卡片、双列且无请求失败。最终汇总报告逐项记录来源，不表述为最初整轮无中断。隔离环境未配置WebTransport，`CHAT_NOT_CONFIGURED`503单列，聊天实时协议不属于本轮浏览器验收结论。

代码与测试就绪，业务测试站发布记录在实际部署后补充。

## 回退边界

0015、0016 为新迁移，不能覆盖既有迁移。数据库含新审核/头像库记录后，旧 API 会重新允许未审核改名和任意头像，因此不能只回退旧二进制。优先前向修复；只回退静态时仍须保留新 API 校验，并确认旧界面的业务提示是否适用。数据库恢复需协调停机和头像媒体，不得删除仍有库、用户或聊天引用的图片。

业务站仅作只读验收，审核、上传和并发写入只在 `qingye_acceptance`。本轮不触发真实短信，不重置注册说明、短信开关或号码白名单；5178 继续 masked，8.140 生产站不变。
