# R10：首页轻滑与代理兼容聊天验收

日期：2026年11月11日。测试版：`0.8.0-test.1`。发布目录：`20261111-chat-proxy-r10`。

## 1. 本轮修改

- 首页“向下探索”改为双下箭头，沿用双主题色彩，加入上下依次明暗的轻动效。
- 首屏前段向下轻滑累计约24px后，复用点击箭头的1.15秒标题变形与入场过渡。滚轮、触控板、单指滑动均接入；向上滚动或再次操作可以中断。表单、导航、弹窗、横向手势与后续商品浏览不触发自动进入。开启减少动画时沿用原有静态内容入口。
- R9背景代码保持不变，保留首页香槟光幕、细线流光和鼠标光晕，不恢复R8网格与双光球。
- 保留WebTransport优先，失败或4.5秒内未就绪时自动申请新票据，切换同源WebSocket。用户端与管理端共用传输适配器，保留原有商品上下文、分配接待、通知和消息记录。
- 不增加业务数据库迁移、商品字段、订单或支付功能。兼容连接使用原有HTTPS端口，服务端不放宽Origin、登录会话、消息归属或频率限制。

## 3. 测试站与Clash验证

两端静态资源和Go程序已发布；Nginx配置检查、API健康检查及外部HTTPS访问通过。实际返回的首页HTML、入口JS/CSS与本地构建逐字节一致，CSP包含各自同源WSS地址。4项公网入口边界检查通过：匿名握手被拒绝，用户入口不暴露管理聊天路由。

本机`127.0.0.1:7890`监听进程为`FlClashCore`。验证客户端显式使用该HTTP代理，没有关闭代理、修改分流规则或关闭TLS校验：

| 身份与连接 | 结果 |
| --- | --- |
| 会员 WSS，经Clash HTTP代理 | 可信TLS、鉴权票据、ready、会话列表RPC和20秒更新心跳通过 |
| 管理员 WSS，经Clash HTTP代理 | 同上，通过 |
| 会员 WebTransport，公网UDP | 可信TLS、ready和会话列表RPC通过 |
| 管理员 WebTransport，公网UDP | 同上，通过 |

公网连接验证仅使用原有测试会员/管理员的临时5分钟会话，测试后已定点撤销，不更改密码，不新增业务咨询或聊天消息。消息写入、并发与越权测试均在独立验收数据库执行。

浏览器工具仍因“failed to write kernel assets / 系统找不到指定的路径”初始化失败。因此，以上是实际代理网络与协议验证，加前端切换逻辑自动化测试；不是Chrome页面内的完整双端收发实测。手机滑动手感、双主题观感和用户Chrome的最终收发仍需人工复核。若代理节点本身无法访问本站或禁止WebSocket，兼容连接也可能失败。
