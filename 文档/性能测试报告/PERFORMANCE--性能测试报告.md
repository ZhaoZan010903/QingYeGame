# 性能测试报告

更新：2026年11月11日。对象：`0.7.0-test.1`隔离验收版本及最终测试部署。仓库迁移后的测试和构建通过，最终R5已部署到5179/5181；以下区分隔离压测、实际业务库只读抽样与浏览器展示检查。

## 最终R5补充

报价迁移后重新在隔离环境执行相同混合读取与写竞争，800次读取错误0，80次写竞争符合幂等/版本预期，28项断言通过。20并发300次：P50 26.87ms、P95 150.74ms、P99 166.84ms；50并发500次：P50 40.32ms、P95 271.16ms、P99 287.73ms。该结果为本机有限样本，不是互联网承载承诺。

实际业务库发布后只读抽样：50条目录响应77,675字节，gzip传输19,000字节；顺序10次API中位9.79ms/P95 18.06ms，5并发10次中位33.27ms/P95 67.39ms，经Nginx gzip顺序10次中位10.79ms/P95 12.91ms，均无错误。与下方R3/R4结果属于不同时间的短样本，不能据差值判定吞吐提升。

R4真实200张图集首屏只请求1张原图和20张缩略图，图片分页最大同时1次；所有图片元数据可继续自动/手动加载。R5修复原图contain和手机放大窗口布局，不把“图片已取得尺寸”视为下载完成，浏览器验收等待complete及decode。完整图集网络耗时受原图体积和链路影响。

## 测量环境与方法

R3并发报告时间为北京时间2026年11月11日02:14:46—02:14:49。脚本在152服务器本机运行，直接访问`127.0.0.1:5184` public API与`127.0.0.1:5185` admin API，使用独立`qingye_acceptance`数据库、Redis6382、系统用户和媒体目录。两个API每进程数据库连接池上限5。

这是HTTP回环请求，未经过互联网、TLS或对外Nginx链路。验收库已导入576条旧商品和48,332条pending媒体元数据，另有脚本创建的专用商品及测试图片；目录查询包含这批旧商品。原始图库文件没有复制到验收媒体目录，图片读取针对测试图片，**不属于完整原图库传输压力测试**。pending媒体与真实ready图片的响应内容也有区别。服务器同机仍有其他应用和迁移任务；资源隔离不等于独立机器。

[验收脚本](../../代码/工具/acceptance_suite.py)使用线程池执行两档短时混合读取，循环访问目录、详情、图集元数据、分类、客服和首页。统计每次请求延迟的P50/P95/P99；只把非200计为读请求失败。测试没有读取全部原始图片，也没有模拟移动端渲染或持续高负载。

## 定位依据与已采取措施

第1轮对业务快照做过只读分层基线：服务器本机目录延迟与外网客户端的秒级尾延迟不在同一量级，不能因此认定数据库慢。其数据量、网络条件和请求数与R3隔离验收不同，不能直接当作优化前后对照；详情见[核心第1轮记录](../业务验收与审查记录/backend-review-round-1--后端第一轮审查.md)。

本轮已实施明确商品字段投影、目录省略重复介绍、预计算推荐分数、稳定分页、详情图集增量加载、缩略图按需生成与加载、图片解码并发控制，以及Nginx JSON gzip。完整标题、详情说明和原图保留。Redis当前用于限流与推荐批次指针，未实现完整商品响应缓存；[缓存职责及后续防击穿方案](../开发产出文档/17-architecture-and-data-flows--架构实体与数据流.md)区分已实现与建议内容。

## 原图完整性与前端证据

北京时间02:15:25的全量核验报告已通过：576个商品图集、48,332条有序关联和48,332张原图全部匹配，逐文件重新计算SHA256，问题数0。原图合计26,841,243,424字节，约26.841GB／24.998GiB。该结果证明指定快照的文件与关联完整性，不是媒体吞吐、下载速度或异地恢复性能。

用户端46项、管理端11项自动化测试及独立管理浏览器17步检查已有通过记录，后者使用真实隔离API，包含上传、发布、下架、双会话及移动宽度。这些是功能与布局证据，不是帧率、LCP或真实手机耗时测量。目录重排后的两个前端已重新安装依赖，46/11项测试及两端构建再次通过；Go构建和19项工具回归也已通过，最终对外切换另记。

## 部署后业务目录抽样

最终部署后，对实际576件公开商品的 `limit=50&sort=newest` 进行只读短样本核查：直连本机API10次顺序请求中位9.615毫秒、P95 14.681毫秒；5并发共10次中位31.716毫秒、P95 65.205毫秒，均无错误。Nginx gzip链路10次顺序请求中位10.086毫秒、P95 12.823毫秒。

本次50条响应JSON为78,929字节，相比早期同参数样本107,947字节减少约26.9%；列表省略重复介绍，详情仍保留。通过Nginx gzip实际传输19,332字节。两次样本发生在不同时间，不能把短样本延迟差异解释为稳定容量提升；这些数值也不包含互联网与页面渲染时间。原始记录为 `post-deploy-performance.json`。

## 复现与覆盖边界

在隔离服务器使用[验收脚本](../../代码/工具/acceptance_suite.py)，依次执行`--phase functional`、`concurrency`、`security`，指定5184/5185目标、对应5186/5187 Origin、专用账户文件及同一轮state。输出报告分开保存；脚本拒绝对业务端口写测试，不得移除此限制。

尚未覆盖长时间稳定性、更大业务规模与全业务混合负载、原图大量并行传输、冷缓存峰值、真实手机及弱网、HTTPS成本、跨地域网络、故障恢复与最大容量。最终对外部署后应分别记录服务器本机与外网链路，并注明gzip、样本量和缓存条件。
