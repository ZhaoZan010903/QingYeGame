# R21-1：筛选与会员资料调整

2026年11月13日，用户授权直接修改代码，完成验证后同步私有 GitHub 并部署 152 测试服务器。范围为下列八项；本轮不恢复 5178 原型，不修改 8.140 生产站。

## 已确认需求

1. 游戏区服按“一舞时光、拾忆光阴、十年之约、其他”排序，历史编码保持不变。
2. VIP 按“星钻、银钻、金钻、彩钻、王钻”排序。
3. 移除账号结构筛选，保留发布字段及历史商品资料。
4. 新增热门关键词筛选，管理员能添加、改名、删除、启停和排序。首批按用户截图录入 23 个词条。
5. 昵称修改经管理员审核才生效，再次修改间隔 30 天；新注册昵称为“清叶会员”加手机尾号。
6. 会员头像只能选择头像库中的图片，管理员维护头像库；首批放入十张卡通漫画头像，涵盖日漫、仙侠与线绘，不放真人照片。
7. 登录页删除左侧人物图片，重新排布标题与说明文字。
8. 首页与账号集市手机端商品卡片每行两个，电脑端三个。

## 实现口径

- 热门筛选复用带版本校验的共享字典，和区服、VIP、价格条件组合。关键词组内取并集，不同筛选组取交集；匹配商品公开标题、简介、区服和标签的字面内容，不把关键词擅自解释为数值规则。
- 昵称冷却期从管理员批准并生效时起计算，使用数据库时间。待审期间保留旧昵称，拒绝后可重新申请；同一会员同时只允许一个待审申请。尾号取手机号后四位。
- 头像库使用现有受控媒体上传、转码与读取。会员旧上传入口在服务端拒绝；管理员上传后加入库，会员只能选启用项。停用项不能再选，已经使用的头像仍展示并保留引用。
- 0015、0016 为新增迁移，不改写已发布迁移。所有写验收在独立 `qingye_acceptance` 环境；业务测试站部署前备份，部署后只读检查。
