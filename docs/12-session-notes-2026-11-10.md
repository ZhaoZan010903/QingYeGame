# 2026年11月10日会话接续记录

这是一份根据本次对话整理的需求与决定记录，不是逐字聊天导出。服务器密码、其他凭据及完整工具输出均未保存。换机器后，可结合私有仓库源码及本文件继续工作。

## 项目为什么重建

原站 qingyeyouxi.com 采用 SaaS 建站，经营方希望自主掌握源码、商品资料、会员、图片与运营配置。目标是技术升级和部分功能优化，不照搬原站所有按钮，也不扩展成复杂在线交易系统。

## 已明确的业务范围

经营模式为平台自营加代售，客服协助交付。围绕 QQ 炫舞账号出售和租赁，保留展示、筛选、详情、客服咨询与客服协助上架；新增用户提交商品、管理员审核及首页热门推荐。

早期讨论曾涉及积分，但后续已收敛为实际可用业务重写。在线充值、积分支付、订单、提现、结算、自动租期等不纳入本轮。推荐权重、报价口径和发布后复审规则仍有待确认项，见 docs/09-review-items.md。

正式技术方向为 React 前端、Go 后端，增加 Redis 及独立图片存储。取消每商品 200 张图片上限；通过分批上传和加载控制资源，不另设固定总张数限制。

## 首页设计如何演进

1. 先整理前期文档，最终采用 Markdown，放入已有私有仓库 QingYeGame。
2. 经营方要求先开发首页确认风格，采用 HTML，本阶段先不推送代码。
3. 认可黑曜石与香槟金方向：暗色细边框、白色按钮、精密数字排版、高清卡片及证书式资料抽屉。禁止青绿色、廉价游戏促销风和高饱和霓虹。
4. 删除主标题说明文案和托管金额、验号耗时等数据面板。
5. 增加精选轮播、热门/最新切换、业务入口、滚动入场、背景流光及鼠标反馈。手机主列表为单列，推荐区域可横向浏览。
6. 经营方要求背景别过于克制、字体效果更明显。本版加强分层金色柔光、光束、弧线和标题银白/香槟金扫光。
7. 经营方随后明确授权：改好后上传 GitHub，并在新指定服务器的 5178 端口部署；希望把接续资料保存在服务器，便于换机访问。
